# 截图占位目录

本目录用于存放论文/PPT 所需的界面截图与录屏素材。请按以下清单自行截取：

- `scan_result.png`：scan.html 单文件分析结果页（含评分圆环、漏洞卡片、CWE 标签）
- `cwe_samples.png`：cwe.html 演示样本库页面
- `posture_dashboard.png`：安全态势仪表盘（index.html/posture.html）
- `theme_transition.gif`：深色/浅色主题切换录屏（展示 View Transition API 交叉淡化）
- `vscode_diagnostic.png`：VS Code 插件在编辑器中标记的红色波浪线诊断
- `intellij_balloon.png`：IntelliJ 插件的气球通知弹窗

要求：PNG 格式优先；录屏转 GIF；命名与上述清单一致，方便素材库和 PPT 引用。
